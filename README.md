# ABHI MUSIC ROYAL EDITION

Telegram group voice-chat music bot.

## Requirements
- Termux
- Python 3
- FFmpeg
- Git
- Telegram API ID, API Hash and Bot Token

## Setup
1. Install Python, FFmpeg and Git.
2. Install dependencies using: `pip install -r requirements.txt`
3. Copy `.env.example` to `.env` and fill in your credentials.
4. Activate `.venv` and run: `python royal_bot.py`

## Security
Never upload `.env`, bot tokens, or Telegram session files.
